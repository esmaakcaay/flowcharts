# flowcharts# 🧠 Flowcharts - Algoritma Temelleri

Bu projede temel algoritma problemlerine ait akış diyagramlarını paylaşıyorum.  
Dosyalar **Draw.io (.drawio)** formatında hazırlanmıştır.

## 📂 İçerik
- Üç sayının en büyüğünü bulan algoritma  
- Üçgenin türünü belirleme 
- Sayının tek/çift olduğunu bulma  

## 💻 Kullanım
Dosyayı açmak için [draw.io](https://app.diagrams.net/) veya [diagrams.net](https://www.diagrams.net/) kullanabilirsiniz.
